# Neon Asteroids (Mouse + Gamepad)

Vector-style Asteroids with neon glow, inertia, screen-wrapping, asteroid splitting, particles, score/lives/levels, pause, and game over.

## Run

From this folder:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Controls

### Mouse + Keyboard (default)
- Aim: mouse (ship points toward cursor)
- Shoot: left click
- Thrust: right click or Space
- Pause: P or Esc
- Fullscreen: F

### Gamepad
- Aim: left stick
- Shoot: RT or A/X
- Thrust: LT or B/Circle
- Pause: Start
- Deadzone adjust: `[` / `]`

### Keyboard-only fallback
- Rotate: A/D or Left/Right
- Thrust: W or Up
- Shoot: Space
